Grammar: Accents

French uses accent marks that change pronunciation.
Accent aigu (é) — acute accent.
Accent grave (è) — grave accent.
Cédille (ç) — turns a "c" before a/o/u into a soft "s" sound.
Tréma (ï) — shows two vowels are pronounced separately.

Gender (Noun Gender) NEW PROFESSOR - REORGANIZED— From Transcript + Gender.pdf

Topic: Noun gender in French - rules, patterns, and how gender affects all other words in a sentence.

All French nouns have a gender: masculine or feminine

Why it matters: Gender affects EVERYTHING in the sentence - articles, adjectives, verb forms

Examples:

la table (feminine) — the table
le livre (masculine) — the book

The gender changes the adjective too:
un étudiant (masculine student)
une étudiante (feminine student)

Golden Rule: Memorize the gender WITH the noun! Say "la table" not just "table"!

RULE 1: -ment endings = MASCULINE
le gouvernement = government
le département = department
l'appartement = apartment

RULE 2: -age endings = MASCULINE
le village = village
le fromage = cheese
le voyage = trip

RULE 3: -oir endings = MASCULINE
le miroir = mirror
le tiroir = drawer

RULE 4: -isme endings = MASCULINE
le tourisme = tourism

RULE 1: -tion or -sion endings = FEMININE
la connexion = connection
une option = option
une décision = decision

RULE 2: -ure endings = FEMININE
la nature = nature
la culture = culture

RULE 3: -ade endings = FEMININE
une promenade = a walk/stroll
une salade = a salad

RULE 4: -e endings = USUALLY FEMININE (with exceptions!)
la table (feminine)
la porte (feminine door)
⚠️ EXCEPTIONS: le père (father), le frère (brother) - both masculine despite -e!

Words borrowed from English are almost always MASCULINE:

le week-end = the weekend
le parking = parking lot
le shopping = shopping
le email = email

Why? French speakers default to masculine when adopting English words.

Tip: When you encounter a modern/tech word from English, assume masculine (le) unless you learn otherwise!

All days of the week are MASCULINE:

le lundi, le mardi, le mercredi, le jeudi, le vendredi, le samedi, le dimanche

All months of the year are MASCULINE:

janvier, février, mars, avril, mai, juin, juillet, août, septembre, octobre, novembre, décembre

All seasons are MASCULINE:

le printemps = spring
l'été = summer
l'automne = autumn
l'hiver = winter
